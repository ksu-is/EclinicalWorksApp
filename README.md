# EclinicalWorksApp
I wanted to test using API's and app development so I'm making an app for my company that's compatible with EClinicalWorks12!!

## What the project does
This app will be used for practice. Its basic capabilities should include:
•	Managing patient credentials
•	Viewing medications
•	Viewing appointments/previous appointment summaries
•	Viewing messages from doctors/nurses/clinical staff
•	A contact page to contact the clinic
•	A policy page for a digital version of a clinic's policies

## Why the project is useful
This project may be useful for anyone wanting a template for a basic IOS application that successfully uses resources from ECW12 to INFORM patients!
